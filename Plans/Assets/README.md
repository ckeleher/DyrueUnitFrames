# Plan assets

Screenshots referenced by plan documents. Named after the plan that uses them:
`Plan_<ID>_<n>.png`.

**Most plans should not have one.** A chat log is worth more transcribed into
the plan than photographed, and most layout complaints are one sentence of
prose. Add an image only when recognizing the thing matters more than describing
it — rendering artifacts, mostly.

Before adding one:

- **crop to the relevant region** — a raw WoW screenshot is ~1.6 MB, a crop of
  the part that matters is 30–80 KB;
- max ~1200px wide;
- PNG for UI panels, JPEG for world scenes;
- hard cap ~200 KB. Over it, crop harder.

Git keeps every binary whole, in every revision, forever. Deleting one later
does not reclaim the space. Full rationale in `Skills/NewWork.md`.
